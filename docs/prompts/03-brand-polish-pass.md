# 03 Brand Polish Pass

## Purpose

Improve a working redesign that still feels like a clean prototype or customized template.

## When To Use It

Use after the first implementation pass builds successfully but the site still lacks premium visual polish.

## Prompt Text

```txt
The site works and the direction is improving, but it still feels too plain or prototype-like.

Do not redesign from scratch.
Keep the current direction and structure.

Perform a brand polish pass focused on:

- Typography refinement
- Logo/wordmark refinement
- Hero copy and spacing
- Visual depth
- Page rhythm
- Card hierarchy
- Button and focus states
- Subtle hover interactions
- Public-facing copy
- Inner page substance
- Footer and contact polish
- Dark mode readability

Avoid:

- Flashy animation
- Trendy overdesigned SaaS effects
- Generic stock imagery
- Random diagrams or filler visuals
- Fake trust claims
- Public developer language

After implementation, run:
npm run check
npm run build

Fix any failures.
```

## Expected Output

- Polished UI changes.
- Copy refinements.
- Interaction/motion improvements.
- Changed file summary.
- Validation results.
- Remaining risks.

## Validation Requirements

Run:

```bash
npm run check
npm run build
```
