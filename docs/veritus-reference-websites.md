# Veritus Reference Websites

## Purpose

This document records the reference websites used to shape the Veritus website direction.

These references were used for presentation, design quality, and category understanding. They were not used for copying content, claims, layouts, or branding.

## Reference Influence Summary

| Reference            | Influence                                                                                       |
| -------------------- | ----------------------------------------------------------------------------------------------- |
| Apple                | Minimal white-first presentation, restrained page rhythm, confident spacing, premium simplicity |
| OpenAI               | Clear technical positioning, calm copy tone, restrained product/company presentation            |
| Vercel               | Developer-product confidence, sharp typography, focused CTAs, clean interface surfaces          |
| Linear               | Refined interaction, polished cards, crisp hierarchy, product-system feel                       |
| Stripe               | Enterprise credibility, structured sections, proof/CTA discipline, business-ready polish        |
| Anthropic            | Calm AI company tone, serious positioning, restrained visual language                           |
| Hermes               | AI automation category framing, agent/workflow concepts, automation-system presentation cues    |
| OpenClaw             | AI/tooling category context, product-oriented visual references, technical workflow framing     |

| Tool/logo references | Operating stack strip and integration-surface credibility without fake customer claims          |

## How Each Reference Was Used

### Apple

Apple influenced the white-first direction, large but controlled typography, quiet spacing, and the idea that a premium page does not need visual noise to feel confident.

Used for:

- White space.
- Minimal surfaces.
- Restraint.
- Premium hero pacing.

### OpenAI

OpenAI influenced the calm, serious tone and the way a technical company can present complex work without excessive decoration or hype.

Used for:

- Copy restraint.
- AI company tone.
- Clear positioning.
- Simple navigation and page rhythm.

### Vercel

Vercel influenced the technical sharpness of the site: confident typography, clear CTAs, and product-like interface presentation.

Used for:

- Typography feel.
- CTA treatment.
- Technical credibility.
- Interface-style visual direction.

### Linear

Linear influenced the expectation that small UI details matter: cards, hover states, spacing, focus, and interaction polish.

Used for:

- Card polish.
- Subtle interaction.
- Product-system feel.
- Visual hierarchy.

### Stripe

Stripe influenced the idea that business websites need credibility, structured sections, and clear conversion paths without fake proof.

Used for:

- Trust/proof structure.
- Enterprise credibility.
- Section organization.
- CTA discipline.

### Anthropic

Anthropic influenced the calm AI-company posture: serious, readable, restrained, and not overdesigned.

Used for:

- AI category tone.
- Public-facing restraint.
- Serious company presentation.
- Avoiding hype language.

### Hermes

Hermes was used as an AI automation category reference, especially around workflow, agents, and automation-system framing.

Used for:

- AI automation category understanding.
- Workflow and agent framing.
- System/control-surface thinking.

### OpenClaw

OpenClaw was used as a technical AI/tooling category reference, especially for understanding how product-like visuals can support automation concepts.

Used for:

- Technical category framing.
- Product visual direction.
- Workflow/tooling presentation cues.

### AstroWind

AstroWind was the technical/theme starting point, but not the final design target.

Used for:

- Astro project foundation.
- Existing route/component structure.
- Static website baseline.

Not used as:

- Final visual standard.
- Final page design.
- Final component style.

### Tool And Logo References

The operating stack strip uses tool/logo references to show the kind of tools modern teams work around.

Used for:

- Technical stack context.
- Integration-surface credibility.
- Operating stack presentation.

Important rule:

- Tool logos are not customer logos.
- Do not label them as "Trusted by."
- Do not imply partnership unless approved.

## Practical Rule For Future Projects

Reference websites should answer:

- How does a premium site present content?
- How much spacing does it use?
- How are CTAs handled?
- How are visuals placed?
- How does the page create trust?
- What does it avoid?

Reference websites should not be used to copy:

- Headlines.
- Claims.
- Brand language.
- Exact layouts.
- Customer proof.
- Visual identity.
