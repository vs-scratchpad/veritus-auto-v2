# Veritus Automation Project Context

> Current repository note: the Astro website project now lives in `veritus-auto/`. Historical references to `src/`, `public/`, `astro.config.ts`, or package scripts in this document refer to files inside `veritus-auto/` unless otherwise stated.

## Purpose

Veritus Automation is a demo/static marketing website for a professional AI automation company. The project uses AstroWind, Astro, and Tailwind CSS to build a polished public site that can later be hosted for free on GitHub Pages.

The assignment came from a request to explore static site generators, choose a free Astro theme, and build a credible business website with marketing collateral, an about page, contact form, examples, and focused campaign landing pages.

## Core Interpretation

The original research direction mentioned Hermes automation or Hermes AI automation. The correct interpretation for this project is AI automation and AI agents, not industrial automation.

Veritus Automation should be positioned around:

- AI agents
- AI workflow automation
- Business process automation
- Document automation
- Support automation
- Sales automation
- Internal knowledge assistants
- Human-in-the-loop approvals
- Tool integrations
- Reviewable outputs
- Governance and auditability

This project should not be positioned around:

- Industrial automation
- PLC or SCADA systems
- Factory control systems
- Electrical panel automation
- Robotics hardware
- Manufacturing-only automation

## Design Direction

The site should feel minimal, airy, spacious, polished, premium, light, modern, calm, and business-focused. The preferred feel is closer to Apple-style product pages than busy SaaS dashboards.

Use AstroWind seriously. Do not reduce the site to a bare hero page. Keep the website content-rich, professional, and useful.

Prefer:

- Clean typography
- Controlled visual density
- Light theme
- Subtle borders
- Calm spacing
- Practical service language
- Original Veritus content

Avoid:

- Neon AI visuals
- Dark-heavy SaaS styling
- Cluttered dashboards
- Fake hype
- Fake metrics
- Fake awards
- Fake testimonials
- Fake customer logos
- Childish illustrations
- Generic template copy
- Competitor names or URLs in public page copy

## Meaning of No Crawl

Treat "no crawl" in two ways:

1. Do not scrape, crawl, or fetch competitor/reference sites.
2. Keep this demo site non-indexed using noindex/nofollow metadata.

GitHub Pages is public hosting. noindex/nofollow reduces search visibility but does not make the site private.

## Campaign Landing Page Concept

Campaign pages are focused pages for one audience or use case. They are useful for future ads, LinkedIn campaigns, email outreach, WhatsApp pitches, QR codes, or targeted sales links.

Do not add campaign pages to the main header navigation. Link to them subtly from homepage workflow cards, the examples page, footer use-case links, or other contextually relevant areas.

Campaign page focus:

- Sales automation: lead qualification, CRM updates, follow-up reminders, pipeline hygiene, and human review before outreach.
- Support automation: ticket triage, suggested replies, routing/escalation, knowledge-base assisted responses, and human approval before final responses.
- Document processing: intake, key-field extraction, validation, exception handling, approval workflow, and export to business systems.
- AI agent readiness: discovery, suitable workflow identification, tool/data/risk mapping, first-use-case prioritization, and governance rules.
