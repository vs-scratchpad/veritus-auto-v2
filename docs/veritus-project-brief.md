# Veritus Automation Project Brief

## Project Goal

Build a professional static marketing website for Veritus Automation using AstroWind, Astro, and Tailwind CSS.

The website is a demo/static site for an AI automation company. It must feel polished, authentic, modern, minimal, and airy. The visual direction should be closer to Apple-style minimal interfaces than busy SaaS dashboards.

The site will eventually be deployed to GitHub Pages.

This project came from an internal assignment to explore Astro/static site generators, choose a free Astro theme, and build a credible marketing website for the Veritus brand. GitHub Pages is public hosting; noindex/nofollow reduces search visibility but does not make the site private.

## Brand

Name: Veritus Automation  
Short logo text: Veritus  
Category: AI automation, AI agents, workflow automation  
Primary positioning: AI agents and workflow automation for modern business teams.

## Core Message

Veritus Automation helps teams turn repetitive business work into reliable AI-powered workflows and agent systems.

## Category Interpretation

The intended direction is AI automation and AI agents, not industrial automation.

The site should focus on:

- AI agents
- AI workflow automation
- business process automation
- document automation
- support automation
- sales automation
- internal knowledge assistants
- human-in-the-loop approvals
- tool integrations
- reviewable outputs
- governance and auditability

The site should not be positioned around:

- industrial automation
- PLC/SCADA
- factory control systems
- electrical panel automation
- robotics hardware
- manufacturing-only automation

## Design Direction

Use AstroWind seriously. Do not strip it down to an empty landing page. Keep useful sections where they improve credibility and completeness.

Preferred style:

- minimal
- airy
- spacious
- premium
- clean typography
- light theme
- controlled visual density
- subtle borders
- calm gradients only if needed
- modern AI/business feel

Avoid:

- neon AI style
- cluttered dashboards
- excessive icons
- fake hype
- dark-heavy layouts
- overfilled sections
- childish illustrations
- copied competitor visuals

- practical

Avoid:

- exaggerated claims
- fake statistics
- fake customer testimonials

- copied competitor wording

## Demo Safety / No Index

This is a demo site. Keep it non-indexed.

Rules:

- Treat "no crawl" as both a competitor research rule and a demo-site indexing rule.
- Do not crawl, scrape, or fetch competitor/reference sites.
- Do not include competitor names in public page copy.
- Do not include competitor URLs in visible content.
- Do not include copied competitor content.
- Do not use real client names.
- Do not create fake client logos.
- Preserve noindex/nofollow metadata.
- Do not add analytics.
- Do not submit or emphasize sitemap behavior.
