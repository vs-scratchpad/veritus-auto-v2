This privacy policy explains the intended privacy posture for the Veritus Automation website.

## Website Data

This website does not add analytics, backend data collection, external form handling, or tracking services.

## Contact Form

The contact form is not currently connected to a message collection service. Information typed into the form is not intentionally collected by Veritus Automation through this website.

## Server and Hosting Logs

If the site is deployed to a hosting platform, that platform may process basic technical information such as request logs, IP address, user agent, or timestamp according to the platform's own practices. This site does not add its own analytics layer.

## Cookies

This site does not intentionally set marketing or analytics cookies. It may use basic client-side behavior from the site framework for theme or navigation interactions.

## No Sale of Personal Information

This site does not sell personal information and does not include advertising pixels or analytics vendors.

## Contact

For questions about this privacy policy, use the contact page.
